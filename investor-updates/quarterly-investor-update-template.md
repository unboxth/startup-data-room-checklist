# Quarterly investor update template

For later-stage companies, or as the longer companion to short monthly emails. Pair it with the board deck if you have a board.

---

**Subject:** [Company] Q[n] [YYYY] update: [headline]

**1. Summary of the quarter** (3-5 bullets, each with a number)

**2. Metrics vs plan**

| Metric | Q[n] actual | Q[n] plan | Q[n-1] | YoY |
|---|---|---|---|---|
| Revenue / ARR | | | | |
| Gross margin | | | | |
| Net revenue retention | | | | |
| New customers | | | | |
| Burn (quarter) | | | | |
| Cash at quarter end | | | | |
| Runway (months) | | | | |

**3. What went well / what didn't** (be candid about the misses and what you changed)

**4. Goals for next quarter** (3 measurable goals, with owners)

**5. Financing** (cash plan, timing of the next raise, any SAFEs or notes issued this quarter and their terms)

**6. Team** (headcount by function, key hires and departures)

**7. Asks**

**Appendix:** P&L, cohort chart, pipeline. Link to the data room folder rather than attaching files.
