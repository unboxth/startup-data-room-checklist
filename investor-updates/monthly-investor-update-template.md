# Monthly investor update template

Copy this into an email (plain text works best), a Google Doc or Notion. Keep it short enough to read on a phone in two minutes. Send it on the same day every month, including the bad months.

---

**Subject:** [Company] investor update: [Month YYYY] · [one-line headline, e.g. "MRR +14%, first enterprise pilot signed"]

Hi all,

**TL;DR**
- [The single most important thing that happened, with a number]
- [Second thing]
- [The ask, if there is one]

**Key metrics** (same metrics, same order, every month)

| Metric | This month | Last month | Change | Plan |
|---|---|---|---|---|
| MRR / revenue | $ | $ | % | $ |
| Customers (paying) | | | | |
| Net revenue retention or logo churn | | | | |
| Pipeline / LOIs | | | | |
| Monthly burn | $ | $ | | $ |
| Cash in bank | $ | | | |
| Runway (months, at current burn) | | | | |

*Definitions: [link to the metrics definitions doc in your data room].*

**Wins**
1. [Win, with a number or a name you have permission to share]
2. 

**Lowlights / what didn't work**
1. [Be specific. Investors trust updates that include the misses.]
2. 

**What we learned**
- [One insight about customers, the market or the product that changed a decision]

**Product**
- Shipped: [feature] → [effect on users or metrics]
- Next month: [top 1-3 priorities]

**Team**
- Hires: [role, start date] · Open roles: [role, link]
- Departures (if any): [role]

**Asks** (the section investors can act on, so make each one specific)
1. **Intro:** [Name / title] at [Company], because [reason]. 
2. **Hiring:** referrals for [role]: [link to job post]
3. **Advice:** [a specific question, e.g. "pricing an annual plan for 50-seat teams"]

Thanks for the support,
[Name]
[Company] · [website]

---

**Before you send:** check that the numbers match the cap table, model and deck in your data room; BCC investors (or use your investor-update tool) so you don't expose everyone's email; mark anything confidential.
