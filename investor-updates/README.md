# Investor update templates

| File | Use it for |
|---|---|
| [monthly-investor-update-template.md](monthly-investor-update-template.md) | The standard monthly update: TL;DR, metrics table, wins, lowlights, learnings, product, team, asks |
| [quarterly-investor-update-template.md](quarterly-investor-update-template.md) | Quarterly update with metrics vs plan and next-quarter goals |
| [investor-update-email-plain.txt](investor-update-email-plain.txt) | A plain-text version that pastes cleanly into any email client |

Habits that make updates work:

- **Same metrics, same order, every month.** Investors compare month to month; changing the table hides the trend.
- **Send the bad months.** A missed month says more than a bad number.
- **Make asks specific.** "Intro to the VP Engineering at a named company" gets answered; "any intros welcome" doesn't.
- **File every update** in `09 Round/` of your data room. New investors ask for the history (row 50 of the [checklist](../checklist/full-checklist.md)).
